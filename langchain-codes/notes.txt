LangChain

Before LangChain:
- Install SDK for your LLM provider
- Create prompts manually
- Send requests to the model
- Handle retries and network failures
- Maintain conversation history if the app is conversational

What is LangChain:
- Open source framework for developing applications powered by LLMs

LangChain Implementation:
- Models
- Prompt Templates
- Output Parsers
- LCEL
- RunnableLambda
- Conversation history
- Context Management


Installing LangChain:
pip install langchain langchain-google-genai


Prompt Template: Reusable prompts
Example:
You are ....
Question ....
Return ....

ChatPromptTemplate
User Question -> ChatPromptTemplate -> System Message -> Human Message -> Gemini

System Prompt

LangChain Output  Parsers
- write binary search in python

Output Parers converts the raw response generated by LLM into the format required by your application

Types of Parers:
- StrOutputParser
- JSON Output
- Pydantic Output Parers
- Custom Parers

Structured Output
Prompt + Model + Parers

LCEL - LangChain Expression Language
- declarative way to connect LangChain components into a reusable pipeline

prompt | model | parser

Runnable
- Everything inside LCEL is a Runnable

RunnableSequence
- LangChain creates a RunnableSequence internally
